# Светлые Сны — сервис бронирования номеров

Учебный проект: сайт гостиницы с каталогом номеров, формой бронирования и панелью администратора для модерации заявок.

Выполнил студент 454 группы: Баженов Илья

Демо работает на **GitHub Pages** (чистая статика: HTML + CSS + JS, без сервера и без БД).

---

## Функционал

### Гость
- Просмотр каталога номеров.
- Фильтрация номеров по категории (Стандарт / Студия / Люкс).
- Бронирование номера через форму.

### Администратор
- Авторизация.
- Просмотр новых заявок.
- Одобрение или удаление заявок.

---

## Технологии

- HTML5
- CSS3 + Bootstrap 5.3.2
- JavaScript (jQuery 3.7.1 slim + Inputmask 5)
- `localStorage` — в качестве хранилища данных

## Хранение данных

Сервера и базы данных нет. Все данные лежат в `localStorage` браузера:

| Ключ                | Что хранит                          |
|---------------------|-------------------------------------|
| `hotel_room_types`  | Категории номеров                   |
| `hotel_users`       | Пользователи (админ)                |
| `hotel_bookings`    | Все заявки на бронирование          |
| `hotel_session`     | Текущая сессия (кто вошёл)          |
| `hotel_seeded`      | Флаг первичной инициализации        |
